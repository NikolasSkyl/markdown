# Changelog

All notable changes to `markdown` will be documented in this file.

## [0.1.0] — 2026-05-07

Initial release.

### Added

- `markdown.to_html` — convert a Markdown document string into an HTML fragment
- MD4C C parser and HTML renderer vendored through Donna FFI
- Tests for headings, emphasis, paragraphs, and unordered lists
- Generated documentation support
